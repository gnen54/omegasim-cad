# Porsche-Kurzchassis mit lenkbarer Vorderachse

Fusion-Archiv **[`CH-PorscheKurzChassisKomplett.f3z`](CH-PorscheKurzChassisKomplett.f3z)** (ca. 67 MB; auf GitHub die Datei öffnen und „Download raw file“ wählen).

Eigene Nachkonstruktion des Porsche-Chassis für Carrera HYBRID (1:50), als gekürztes Chassis, komplett mit:

| Komponente | Inhalt |
|---|---|
| CH-PorscheKurzChassisKomplett | Baugruppe (Hauptdatei) |
| CH-PorscheChassisVorderachse | Vorderachse mit Drehgelenken der Vorderräder (Grenzen ±30°, 0° = geradeaus) |
| CH-VorderradLenkVorderachse | Lenkung der Vorderräder |
| CH-Achsschenkel_a | Achsschenkel |
| CH-ProfilReifenVorne_a | Vorderreifen mit Profil |
| HinterRadKomplett | Hinterrad, Felge angelehnt an die Sturmkind-Originalfelge (eigene Nachkonstruktion, keine Originaldatei) |
| CH-Unterbau | Unterbau |
| CH-Controller | Controller-Platine als Platzhalter |

## Benutzen

1. In Fusion **Datei → Öffnen → Von meinem Computer öffnen** und die `.f3z` wählen. Fusion legt alle Komponenten im aktiven Projekt an.
2. Eigene Karosserie als Netz oder Körper einfügen, **ohne das Chassis zu verschieben**.
3. Mit dem Add-In [Lenkeinschlag](../fusion-addins/LenkeinschlagAddIn/) die Vorderräder einschlagen und den Freiraum in den Radhäusern prüfen.
